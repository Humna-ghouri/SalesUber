# SalesUber

SalesUber is a modern telecom sales and marketing landing website built with React and Vite. The project presents a professional brand experience for a telecom sales company that helps cable and internet providers acquire customers and grow their business.

## Project Overview

This website focuses on:

- Promoting telecom sales and customer acquisition services
- Highlighting company credibility and expertise
- Showing why customers should choose SalesUber LLC
- Providing a clean contact page for leads and inquiries
- Delivering a responsive, mobile-friendly experience

## What This Project Includes

The project includes multiple sections and pages:

- Hero section with animated background image slider
- About Us section with company profile and value proposition
- Why Choose Us section with trust and growth messaging
- Our Expertise section showcasing service categories
- Contact page with contact details, form, and Google map embed
- Responsive navigation bar with mobile menu
- Footer with company info and social links

## Tech Stack Used

- React
- Vite
- JavaScript
- React Router DOM
- Tailwind CSS
- Framer Motion
- Font Awesome
- CSS custom styling

### Home
The home page introduces the brand and showcases the telecom sales story with a high-impact layout and animated hero design.

### Contact

## Installation

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Navigate to the project folder:

```bash
cd SalesUber
```

3. Install dependencies:

```bash
npm install
```

## Run the Project

Start the development server:

```bash
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build for Production

```bash
npm run build
```

## Preview Production Build

```bash
npm run preview
```

## Notes

This project is designed as a business/marketing website for a telecom sales company and uses modern UI patterns for trust-building, branding, and contact generation. The codebase is lightweight and suitable for a startup-style service business website.
